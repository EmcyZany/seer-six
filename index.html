Market types

Built to escape the binary

Categorical

One outcome from a defined set wins. The familiar yes/no market, generalised.

Scalar

Trade where a value lands inside a range — a distribution, not a coin flip. Scalar markets are drawn as probability waves, never donuts.

Multi-outcome

Dozens or hundreds of outcomes in a single market, with weights that sum to 100% — the shape Deep is built on.

Futarchy

Two conditional markets price the same metric — if a proposal passes, and if it does not — so a DAO can see the expected impact before it decides.

Trust stack

Resolved in the open

Reality.eth

Every market anchors to an explicit, machine-readable question, answered optimistically with bonds and a challenge window.

Kleros Court

Disputed answers escalate to decentralised jurors — arbitration as a backstop, not a black box.

Gnosis Conditional Tokens

Positions are minted against collateral on the Conditional Token Framework, and collateral can earn yield while markets run.
